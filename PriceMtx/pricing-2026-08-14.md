## 2. Anthropic — API (metered) **[V]**

Source: <https://platform.claude.com/docs/en/about-claude/pricing>

| Model | Input $/MTok | Output $/MTok | Cache read $/MTok | Cache write (5m / 1h) |
|---|---|---|---|---|
| Claude Fable 5 | 10.00 | 50.00 | 1.00 | 12.50 / 20.00 |
| Claude Opus 5 | 5.00 | 25.00 | 0.50 | 6.25 / 10.00 |
| Claude Opus 4.8 / 4.7 / 4.6 / 4.5 | 5.00 | 25.00 | 0.50 | 6.25 / 10.00 |
| Claude Sonnet 5 | 2.00 | 10.00 | 0.20 | 2.50 / 4.00 |
| Claude Sonnet 4.6 / 4.5 | 3.00 | 15.00 | 0.30 | 3.75 / 6.00 |
| Claude Haiku 4.5 | 1.00 | 5.00 | 0.10 | 1.25 / 2.00 |

Cost levers on the metered path, all documented:

- **Batch API — 50% off input and output.** Non-interactive work only.
- **Prompt caching** — cache read is 0.1× base input. Pays back after one read on the
  5-minute cache, two reads on the 1-hour cache.
- **Discounts stack** — batch × caching combine.
- Web search: **$10 per 1,000 searches**. Web fetch: no charge beyond tokens.
- Code execution: **1,550 free container-hours per org per month**, then $0.05/hour.
- Managed Agents: tokens at the rates above **plus $0.08 per session-hour**.
- Fast mode (Opus 5 / 4.8, Claude API only): $10 / $50 per MTok.
- Pinning inference to US (`inference_geo: "us"`): **1.1× on everything**. Relevant only
  if a client contract forces US-only routing.
- Tokenizer note: Claude 4.7 and later produce **~30% more tokens for the same text**
  than 4.6 and earlier. Any token estimate carried over from an older model understates
  cost on current models.

## 4. GitHub Copilot **[V]**

Source: <https://github.com/features/copilot/plans>

| Plan | Price | Included credits | Flex allotment |
|---|---|---|---|
| Free | $0 | 2,000 completions + 50 chat requests/mo | — |
| Pro | $10/mo ($120/yr) | $15/mo credits, unlimited completions | $5/mo |
| Pro+ | $39/user/mo ($468/yr) | $70/mo credits, "4×+ included usage than Pro" | $31/mo |
| Max | $100/user/mo ($1,200/yr) | $200/mo credits, "2.9×+ Pro+" | $100/mo |

- All tiers list the same model menu (Claude, GPT, Gemini, MAI-Code, Grok, Kimi variants).
- Credits are quoted **in dollars**, so Pro+ nominally returns $70 of credit for $39, and
  Max $200 for $100. Whether a Copilot credit-dollar buys the same work as an API dollar
  is **unverified** — do not treat the 2× as free money until tested.
- **Business and Enterprise per-seat tiers were not on this page. [gap]** Those are
  normally the ones with org admin/policy controls, so this gap matters for a company buy.
